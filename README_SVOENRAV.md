# SVOENRAV ERP

Собственная копия открытой ERPNext 16.53.0 для кожевенной мастерской SVOENRAV.
Исходные модули ERPNext сохранены: производство, склад, закупки, продажи,
финансы, качество, обслуживание и проекты. Изменения мастерской находятся в
модуле `erpnext/svoenrav` и на странице `/svoenrav`.

Программа работает на вашем компьютере. Подписка Frappe Cloud не требуется.
GitHub хранит исходный код; для работы программы должен быть включён компьютер
с Docker Engine и Docker Compose. GitHub Pages для этой серверной ERP не используется.

## Запуск

1. Установите Docker с поддержкой Docker Compose и Python 3.10 или новее.
2. Скачайте этот репозиторий целиком или клонируйте его.
3. В папке проекта выполните:

   ```console
   python tools/svoenrav.py start
   ```

   В Windows также можно открыть `SVOENRAV_START_WINDOWS.bat`.
   На macOS — `SVOENRAV_START_MAC.command` после разрешения его запуска.

4. Откройте http://localhost:8080/svoenrav. Первый запуск скачивает образы,
   собирает локальную копию и создаёт базу, поэтому занимает больше времени.
5. Логин — `Administrator`. Случайный пароль сохраняется в
   `.svoenrav/credentials.txt`. Пароли и рабочие данные исключены из Git.
6. Завершите стандартный мастер настройки ERPNext: укажите реальные данные
   организации, страну, валюту и начальные настройки. Они не выдумываются проектом.

Доступ с телефона в своей локальной сети включается явно:

```console
python tools/svoenrav.py start --lan
```

На телефоне откройте `http://IP-компьютера:8080/svoenrav`. По умолчанию приложение
доступно только на самом компьютере. Эта конфигурация предназначена для локальной
работы; внешняя публикация в Интернет требует отдельной настройки HTTPS и доступа.

## Самостоятельная настройка

На стартовой странице есть ссылка **Настроить SVOENRAV**. Владелец с ролью
`System Manager` может менять название, описание, цвет и список действий.
Меню задаётся обычным JSON: название кнопки, пояснение, документ и режим открытия.
В настройках приведён пример. Новые существующие типы документов также допускаются.
Права пользователя проверяются отдельно для каждой кнопки.

Поля и расположение полей настраиваются стандартным **Customize Form**.
Права — **Role Permission Manager**. Согласования — **Workflow**.
Печатные формы — **Print Format**. Состав изделий и нормы — **BOM**.
Форма настроек не перезаписывается при повторном запуске или миграции базы.

Штатные документы ERPNext остаются доступными из полного рабочего стола.
Начальная панель сокращает навигацию; новые специализированные диалоги приёмки,
раскроя и выпуска можно добавлять в модуле SVOENRAV по мере утверждения процесса.

## Что подготовлено

- Полный исходный код ERPNext; версия, коммит источника и лицензия сохранены.
- Локальная Docker-конфигурация с постоянными томами базы и файлов.
- Случайные пароли вместо демонстрационных `admin/admin`.
- Настраиваемая русская стартовая страница и список доступных производственных заданий.
- Проверка прав и защита настроек от произвольных ссылок и HTML.
- Команды остановки, просмотра состояния, журналов и резервного копирования.
- Проверки добавленного кода, работающие без установки всей ERPNext.

Реальные остатки, цены, фотографии и производственные нормы в проект не вшиты.
Перенос книги SVOENRAV v2.1, её кодов моделей и непрерывного журнала номеров —
отдельная миграция после выбора целевой базы. Стандартная нумерация ERPNext сама
по себе не считается подтверждением сохранения прежней сквозной нумерации.

## Команды

```console
python tools/svoenrav.py check
python tools/svoenrav.py start
python tools/svoenrav.py status
python tools/svoenrav.py logs
python tools/svoenrav.py backup
python tools/svoenrav.py stop
python -m unittest discover -s tests/svoenrav -v
```

`stop` сохраняет данные. Команды удаления базы намеренно нет.
Резервные копии копируются в `.svoenrav/backups`; их следует хранить и вне этого компьютера.

Собственная сборка добавляет Python-модуль и серверную HTML-страницу к официальному
образу ERPNext той же версии. Изменение основных JS/CSS-пакетов ERPNext потребует
полной пересборки assets стандартными средствами Frappe; этот начальный образ
не подменяет такую сборку. Текущая панель не требует JS-пакетов или внешних CDN.

## Проверка и происхождение

См. [обзор исходного проекта](svoenrav/UPSTREAM_STUDY.md) и
[зафиксированные версии](svoenrav/upstream.json).

в `.github/upstream-workflows` и не запускаются в вашем аккаунте сами.
Платные API, облачные серверы и платные подписки этим проектом не создаются.

Лицензия ERPNext — GNU GPL v3, см. неизменённый `license.txt`.
Исходные авторы и уведомления сохранены. Изменения SVOENRAV распространяются
на тех же условиях. Контейнерная схема адаптирована из `frappe/frappe_docker`;
её MIT-лицензия сохранена в `svoenrav/licenses/frappe_docker_LICENSE`.

В текущей среде проверены исходники, настройки, генерация конфигурации и тесты
добавленного кода. Полный запуск контейнеров требует Docker; здесь он недоступен.
