# Подготовка данных к переносу

CSV в этой папке — пустые рабочие таблицы для сбора исходных данных, **не готовые
шаблоны Data Import ERPNext**. Данные не загружены. Книгу SVOENRAV v2.1 в этой
доработке не читали и не преобразовывали. После запуска ERP необходимо получить
шаблоны импорта из целевой базы и проверить обязательные поля и ссылки.

Не помещайте заполненные таблицы с рабочими данными, клиентами и ценами в публичный
репозиторий. Заполненные файлы можно хранить вне папки репозитория.

| Таблица | Назначение | Целевая сущность |
|---|---|---|
| materials.csv | Артикулы материалов и единицы | Item, Item Group, UOM; поставщики отдельными справочниками |
| products.csv | Коды моделей, варианты, единицы | Item; схема вариантов после сверки |
| bom_materials.csv | Материалы, нормы и количество базового выпуска | BOM и дочерние строки материалов |
| serial_history.csv | Ранее выданные индивидуальные номера | Сопоставление с Serial No, затем отдельная миграция |

## Правила заполнения

- `source_reference` — лист/строка исходной книги или другой проверяемый источник.
- `stock_uom` / `material_uom` — однозначная единица. Нельзя оставлять площадь
  как «штуки» без отдельного измерения шкуры.
- `conversion_factor` — число складских единиц в одной закупочной единице.
  Например, если складская единица дм², а закупочная м², коэффициент равен 100.
  Если закупочная единица — шкура с переменной площадью, постоянный коэффициент
  не заполняется: нужно согласовать приёмку фактической площади.
- `bom_output_qty` — на сколько изделий указана норма `material_qty`.
- `serial_number` — сохранять текстом, включая ведущие нули. Не переименовывать
  старые номера автоматически. Уникальность проверяется по полному старому журналу.
- Пустые нормы, цены и неизвестные значения не заменять нулями. Цены и остатки
  загружаются отдельно после подтверждения даты перехода.

Перед переносом: сверить дубликаты артикулов, несовместимые единицы, отсутствующие
материалы в BOM и повторяющиеся индивидуальные номера. Затем пробная загрузка
одной модели в тестовую базу. Файлы не содержат выдуманных примеров изделий.
